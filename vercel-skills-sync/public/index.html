Skills Library sync-worker

This is a headless worker, not a website — it has no page to browse. Its only job is POST /api/sync (with a Bearer token), which calls skills.sh's official API and writes real skills into the Supabase database that tools.scult.in/skills reads from.

It's driven by a scheduled GitHub Actions workflow in the main repo and a daily Vercel Cron as a backup. See vercel-skills-sync/README.md in the repo for how it works.
