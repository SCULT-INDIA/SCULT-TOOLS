03 — The signature component

Neo-brutalist pill

Yellow fill, 1px black border, 100px radius, and a hard 7px 7px 0 0 #000 shadow. On hover the button translates into its own shadow. Hover them.

The 1px black border is not decoration — the yellow fill is only 1.61:1 against white, so the border is what satisfies WCAG 1.4.11 for the control's boundary. Do not remove it.
