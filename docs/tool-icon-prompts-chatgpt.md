# Scult Tools — 15 ChatGPT Icon/Graphic Prompts (one per tool)

Brand lock for every prompt: flat vector, deep-violet #4B20DE line/fill only,
1024x1024 transparent PNG, no gradients/3D/photoreal, no lucide-style generic
glyphs — each is a custom illustrated OBJECT metaphor for the tool, matching
`lib/tools/registry.ts`'s 15-tool catalogue in category order (SEO, Business,
Developer, Productivity, Design, GEO/AEO).

Paste each block into ChatGPT image generation. Drop finished PNGs back into
chat with Claude to wire into `components/ui/Icon.tsx` / tool cards.

## 1. Schema Markup Generator

```
Design a single custom flat-vector icon illustration, 1024x1024px, transparent background, PNG, for a tool called "Schema Markup Generator" (it turns plain content into JSON-LD structured data for search engines).

CONCEPT: a stack of three overlapping curly braces { } morphing into a small tag/label shape — visualize structured data as a neatly organized filing tag. Specifically: draw a single rounded price-tag / bookmark-tag shape (like a luggage tag with a small punched hole at the top-left corner and a short loop), and inside the tag, nested curly braces {{ }} drawn in a slightly smaller scale, with two tiny dots representing key-value pairs (one dot, one short dash) sitting between the braces like ": value".

STYLE:
- Flat vector, single-color line + fill in deep violet #4B20DE only (no other colors, no gradients).
- Consistent stroke weight throughout, rounded line caps and joins (soft, friendly, matches a Fraunces/Recoleta-adjacent warm geometric feel — NOT sharp technical/blueprint style).
- Sit the whole illustration inside an invisible 1024x1024 canvas with generous padding (icon occupies the center ~65% of the frame).
- No background shape, no card, no shadow — icon only, fully transparent PNG, ready to be placed onto a colored pastel tile by a designer later.
- No text, no letters, no numbers baked into the artwork.
- Absolutely NOT a generic "code brackets </>" icon, NOT a magnifying glass, NOT a lucide/feather/heroicons-style thin-line icon — this must read as a small bespoke illustrated object, slightly playful, with rounded organic terminals like a hand-drawn but precise vector.

Output: one clean icon, centered, transparent background.
```
